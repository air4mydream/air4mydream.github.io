อัปเดตรูปปก Famicom บนหน้ารวมแพตช์ v1.3

ใช้กับ repository air4mydream/air4mydream.github.io เท่านั้น

วิธีอัปเดต
1. แตกไฟล์ ZIP นี้
2. เปิด https://github.com/air4mydream/air4mydream.github.io/upload/main
3. ลากไฟล์ index.html และโฟลเดอร์ assets จากชุดนี้เข้าไปพร้อมกัน
   ต้องเห็น index.html และ assets/cover-famicom-th-hd-v1.3.png ที่ระดับแรกของ repository
   ไม่ต้องอัปโหลด ZIP หรือโฟลเดอร์ครอบ JohnLowery_Home_Cover_Update_v1.3
4. กด Commit changes แล้วรอ GitHub Actions ของ Pages สำเร็จ
5. เปิด https://air4mydream.github.io/ แล้วกด Ctrl+F5

ไม่ต้องลบไฟล์อื่นใน assets เดิม และไม่ต้องเปลี่ยนไฟล์ใน repository ของหน้าแปะแพตช์ทั้งสองเกม

ภาพใหม่ใช้ต้นฉบับสแกนความละเอียดสูงร่วมกับรูปแบบชื่อไทยจากปกเดิม
ชื่อบนภาพ: ซันเป้ / เจ้าหนูนักตกปลา / ภาค บลูมาร์ลิน
ขนาดภาพ: 1494 × 1052 พิกเซล
การแก้ภาพใช้ imagegen ซึ่งอาจทำให้รายละเอียดลายเส้นบางจุดต่างจากภาพสแกน

ตรวจแล้ว: ลิงก์ทั้งสองเกมและ stylesheet เดิมคงอยู่ รูปใหม่มีอัตราส่วนกำหนดถูกต้อง
ยังไม่ได้อัปโหลดหรือเผยแพร่ขึ้น GitHub และไม่ได้ตรวจหน้าเว็บด้วยเบราว์เซอร์
